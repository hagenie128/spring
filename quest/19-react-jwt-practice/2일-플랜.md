## CRUD Postman 10분 테스트 (매일 끝에)

```
1. login → token
2. GET  /api/posts        (R)
3. GET  /api/posts/1      (R)
4. POST /api/posts        (C)  ← URL 끝에 숫자 X
5. PATCH /api/posts/1     (U)
6. DELETE /api/posts/1    (D)
```
