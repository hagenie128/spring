# B-00 — React 프로젝트 직접 만들기 (30분 목표)

> **목표:** `create-react-app`으로 빈 React 앱을 만들고 폴더만 잡는다.  
> **백엔드:** `step17-board-backend` (8888) 실행 중이어야 함.

---

## 1. 프로젝트 생성

```powershell
npx create-react-app jwt-api-practice
cd jwt-api-practice
npm install axios react-router-dom
```

---

## 2. 환경 변수

프로젝트 루트 `.env`:

```
REACT_APP_API_URL=http://localhost:8888
```

⚠️ `.env` 수정 후 `npm start` **재시작**

---

## 3. 폴더 구조

```
src/
├── api/
│   ├── axiosInstance.js
│   └── authApi.js
├── context/
│   └── AuthContext.jsx
├── pages/
│   ├── LoginPage.jsx
│   └── ItemListPage.jsx    ← 게시글/도서/학생 목록 (이름은 자유)
├── App.js
└── index.js
```

---

## 4. index.js 최소 구조

```jsx
<BrowserRouter>
  <AuthProvider>
    <App />
  </AuthProvider>
</BrowserRouter>
```

`AuthProvider` 없이 `useAuth()` 쓰면 에러 납니다.

---

## 5. 실행

```powershell
npm start
```

http://localhost:3000
