# A-00 — Spring Boot + MyBatis + Thymeleaf 프로젝트 직접 만들기

> **목표:** IDE/Initializr만으로 빈 프로젝트를 만들고, DB까지 연결한다.  
> **연습 도메인:** 도서 관리 (`books`) — 학생관리와 같은 CRUD 짜임

---

## 1. Spring Initializr 설정

https://start.spring.io/

| 항목 | 값 |
|------|-----|
| Project | Gradle - Groovy |
| Language | Java |
| Spring Boot | 3.4.x 또는 3.5.x |
| Java | 17 또는 21 |
| Group | `com.spring` |
| Artifact | `book-crud-practice` |
| Packaging | Jar |

### Dependencies (필수 4개)

- **Spring Web**
- **Thymeleaf**
- **MySQL Driver**
- **Validation**

### Dependencies (추가로 직접 넣을 것)

`build.gradle`에 MyBatis 수동 추가:

```gradle
implementation 'org.mybatis.spring.boot:mybatis-spring-boot-starter:3.0.5'
compileOnly 'org.projectlombok:lombok'
annotationProcessor 'org.projectlombok:lombok'
```

## 2. 폴더 구조 만들기 (빈 파일 생성)

```
src/main/java/com/spring/
├── BookCrudApplication.java
├── controller/
│   └── BookController.java      ← 나중에 작성
├── service/
│   └── BookService.java
├── mapper/
│   └── BookMapper.java
└── dto/
    └── BookDTO.java

src/main/resources/
├── application.properties
├── mappers/
│   └── book-mapper.xml
├── schema.sql                   ← DB 테이블
└── templates/
    └── book/
        ├── list.html
        ├── detail.html
        ├── form.html
        └── edit.html
```

**시험 팁:** 패키지 이름은 문제지에 맞추고, **폴더 역할(controller/service/mapper/dto/templates)** 만 기억하세요.

## 3. application.properties

```properties
spring.application.name=book-crud-practice
server.port=8080

spring.thymeleaf.cache=false

spring.datasource.url=jdbc:mysql://localhost:3306/book_practice_db
spring.datasource.username=root
spring.datasource.password=본인비번
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

mybatis.mapper-locations=classpath:/mappers/**/*.xml
mybatis.type-aliases-package=com.spring.dto
mybatis.configuration.map-underscore-to-camel-case=true
```

## 5. MyBatis 연결 확인 (최소 코드)

**BookMapper.java**
```java
@Mapper
public interface BookMapper {
    List<BookDTO> findAll();
}
```

**book-mapper.xml**
```xml
<select id="findAll" resultType="book">
    SELECT * FROM books ORDER BY book_id DESC
</select>
```

**BookCrudApplication.java** — Mapper 스캔
```java
@SpringBootApplication
@MapperScan("com.spring.mapper")
public class BookCrudApplication { ... }
```

**BookDTO.java**
```java
@Alias("book")
@Getter @Setter
public class BookDTO {
    private Long bookId;
    private String title;
    private String author;
    private Integer price;
    private String publishedDate;
}
```
