## 연습 1 — 메뉴 관리로 바꾸기 (30분)

문제지를 이렇게 받았다고 가정하세요.

```
테이블: menus
- menu_id (PK)
- name (메뉴명, NOT NULL)
- category (카테고리)
- price (가격)
- is_available (판매여부 1/0)

URL: /menus
기능: 목록, 상세, 등록, 수정, 삭제
```

### 할 일

1. `books` 관련 이름을 전부 `menus` / `Menu` 로 치환
2. `schema.sql` 새로 작성
3. Mapper XML 컬럼명 수정
4. Thymeleaf 템플릿 폴더 `templates/menu/`

### 치환 표

| 도서 관리 | 메뉴 관리 |
|-----------|-----------|
| `books` | `menus` |
| `BookDTO` | `MenuDTO` |
| `bookId` | `menuId` |
| `title` | `name` |
| `author` | `category` |
| `/books` | `/menus` |

## 연습 3 — 검색 추가 (보너스, 20분)

목록에 **저자명 검색** 추가.

```
GET /books?keyword=김
```

- Controller: `@RequestParam(required=false) String keyword`
- XML: `WHERE author LIKE CONCAT('%', #{keyword}, '%')`
- list.html: 검색 `<form method="get">`

시험에 검색이 나오면 **목록 쿼리 1개 + keyword if** 패턴입니다.

---

## 실수 방지 체크

| 실수 | 증상 | 해결 |
|------|------|------|
| `@MapperScan` 누락 | Mapper bean 없음 | Application에 추가 |
| `resultType` 오타 | 조회 null | `@Alias("book")` 와 XML 일치 |
| `th:action` POST URL 틀림 | 404 | `@{/books/{id}/delete(id=...)}` |
| redirect 끝에 `.html` | 404 | `redirect:/books` (뷰 이름 X) |
| snake_case 매핑 | 필드 null | `map-underscore-to-camel-case=true` |
