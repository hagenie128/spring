## URL 설계 (암기용 패턴)

| 기능 | Method | URL | View |
|------|--------|-----|------|
| 목록 | GET | `/books` | `book/list` |
| 상세 | GET | `/books/{id}` | `book/detail` |
| 등록 폼 | GET | `/books/new` | `book/form` |
| 등록 처리 | POST | `/books` | redirect → `/books` |
| 수정 폼 | GET | `/books/{id}/edit` | `book/edit` |
| 수정 처리 | POST | `/books/{id}/edit` | redirect → `/books/{id}` |
| 삭제 | POST | `/books/{id}/delete` | redirect → `/books` |

학생관리면 `/books` → `/students`, `bookId` → `studentId` 로 치환.

## 문제 4 — 수정 (Update)

### TODO

| # | 파일 | 할 일 |
|---|------|-------|
| 1 | Mapper | `void update(BookDTO book)` |
| 2 | XML | `UPDATE books SET ... WHERE book_id = #{bookId}` |
| 3 | Controller | `GET /books/{id}/edit` — findById로 폼에 기존값 |
| 4 | Controller | `POST /books/{id}/edit` → `redirect:/books/{id}` |
| 5 | edit.html | form.html 복사, `th:action`만 수정 URL로 |

### Mapper XML 예시

```xml
<update id="update">
  UPDATE books
  SET title = #{title},
      author = #{author},
      price = #{price},
      published_date = #{publishedDate}
  WHERE book_id = #{bookId}
</update>
```

### Controller 예시

```java
@GetMapping("/{id}/edit")
public String editForm(@PathVariable Long id, Model model) {
  model.addAttribute("book", bookService.findById(id));
  return "book/edit";
}

@PostMapping("/{id}/edit")
public String edit(@PathVariable Long id, @ModelAttribute BookDTO book) {
  book.setBookId(id);
  bookService.update(book);
  return "redirect:/books/" + id;
}
```

### edit.html

```html
<form th:action="@{/books/{id}/edit(id=${book.bookId})}" th:object="${book}" method="post">
  <input th:field="*{title}" />
  <!-- author, price, publishedDate 동일 -->
  <button type="submit">수정</button>
</form>
```

**완료:** 수정 후 상세에 반영

### Mapper XML


### Controller

```java
@PostMapping("/{id}/delete")
public String delete(@PathVariable Long id) {
  bookService.deleteById(id);
  return "redirect:/books";
}
```

### detail.html — 삭제는 POST form!

```html
<form th:action="@{/books/{id}/delete(id=${book.bookId})}" method="post"
      onsubmit="return confirm('삭제하시겠습니까?');">
  <button type="submit">삭제</button>
</form>
```

⚠️ `<a href=".../delete">` GET 삭제는 시험에서 감점·오류 원인
